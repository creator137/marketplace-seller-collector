Инструкция по работе

Все действия выполняются в интерфейсе — команды и доступ к серверу не нужны.
Обычный порядок: проверить сессию → выбрать города и категории → запустить сбор → проверить статус → скачать результат.

1. Обновить сессию маркетплейса

  1. Откройте Справочники → Сессии.
  2. У нужной площадки нажмите «1. Открыть Chromium». Откроется отдельное окно браузера сервера.
  3. Дождитесь обычной страницы маркетплейса. Если появилась проверка — пройдите её вручную.
  4. Вернитесь на страницу сессий и нажмите «2. Сохранить cookies».
  5. Если задача была приостановлена, откройте её в Истории и нажмите «Продолжить сбор».
Если Ozon показывает «Похоже, нет соединения», это блокировка IP сервера, а не captcha. Сохранение cookies в этом случае не поможет — для Ozon потребуется другой исходящий IP.

2. Выбрать города и категории

  1. Перейдите в Новый сбор и выберите маркетплейс.
  2. В поле поиска города начните вводить название, затем нажмите на нужный город. Можно выбрать несколько.
  3. В поле поиска категории введите часть названия и выберите одну или несколько категорий.
  4. Пункты «Все города» и «Все категории» выбирают весь активный справочник.
  5. Укажите, сколько продавцов нужно получить, и нажмите «Начать сбор».

Город продавца определяется по юридическому адресу, а не по городу доставки покупателя. Поэтому часть найденных продавцов может не попасть в выбранный городской фильтр.

Откуда берутся категории

Wildberries
Из публичного меню WB. Обновляются автоматически раз в сутки.
Яндекс.Маркет
Из официального файла категорий Яндекса. Обновляются автоматически раз в сутки.
Ozon
Из сохранённого дерева каталога Ozon, так как площадка блокирует текущий IP сервера.

Посмотреть список, найти категорию, включить или выключить её можно в Справочники → Категории. Поле «Внешний ID» служебное; при обычном запуске ориентируйтесь на название категории.

3. Следить за сбором и продолжить после блокировки

  • В очереди — задача ожидает worker.
  • Выполняется — страницу можно закрыть, сбор продолжится на сервере.
  • Завершён — цель достигнута и результат готов.
  • Завершён частично — получено меньше заданного количества; откройте задачу, чтобы увидеть причину или продолжить до цели.
  • Приостановлен — площадка запросила новую сессию или ограничила запросы.
  • После обновления сессии нажмите «Продолжить сбор». Сбор продолжится с сохранённой точки.

4. Найти продавцов и скачать Excel

  1. Откройте раздел Продавцы.
  2. Используйте фильтры маркетплейса, поиск по городу, названию, ИНН или адресу.
  3. На странице конкретной задачи кнопка «Экспорт XLSX» скачивает только продавцов этого запуска.
  4. Кнопка «Экспорт всех» скачивает всю накопленную базу.

Повторный запуск не создаёт дублей: данные продавца и контакты дополняются.

5. Дозаполнить телефоны

На странице «Продавцы» нажмите «Дозаполнить телефоны». Система использует ИНН и юридический адрес из DaData, затем ищет публичную карточку организации. Не запускайте операцию повторно, пока предыдущая ещё выполняется.
